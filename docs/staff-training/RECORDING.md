# Recording checklist (human voice + real RuffOps UI)

## Environment

- URL: https://fitdog.ruffops.com/admin/login (or staging equivalent)
- Account: dedicated training login with **fake** owners/dogs only
- Resolution: 1920×1080, cursor visible, system UI chrome hidden
- Audio: lapel or condenser mic; **live human** narration from scripts in `lib/staff-training/scripts/`

## Per-lesson workflow

1. Read the script aloud once for timing (~durationMinutes in catalog).
2. Screen record the exact clicks listed in `guidedSteps` for that lesson.
3. Pause 2–3 seconds on each button before clicking (editor can add highlights).
4. Export MP4 + optional VTT; upload per `MAINTENANCE.md`.
5. QA: captions match script; no real phone numbers or addresses on screen.

## Not complete in automation

- Human voiceover files are **not** generated by this repo.
- Most `videoStatus` values remain `pending_capture` until Fitdog records on site.
