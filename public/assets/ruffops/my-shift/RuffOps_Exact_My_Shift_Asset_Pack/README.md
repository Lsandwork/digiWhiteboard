# RuffOps My Shift — Exact Graphics Asset Pack

This is a **reference-derived asset pack**, not an AI-generated mockup.

All screenshot crops in this pack come directly from the user-supplied RuffOps My Shift reference. It includes the dog hero image, team portraits, visible icon graphics, logo crop, background/panel fragments, paw watermark reference, and scalable KPI sparkline SVGs.

## Use
1. Extract this ZIP into your RuffOps project (or an assets staging folder).
2. Open `07-cursor/CURSOR-EXACT-INTEGRATION-PROMPT.md` in Cursor and use it as the implementation brief.
3. Tell Cursor to inspect the existing app and integrate these exact assets into the existing My Shift route.

## Important
- The exact screenshot crop of the RuffOps wordmark is provided for visual reference. If your project contains the official source logo/vector, use that official asset for production.
- Cropped icon PNGs include their original screenshot pixels. Transparent variants are best-effort background-keyed exports; compare with the original crop if any edge looks imperfect.
- Do not use the screenshot as the entire page background; the app should be built from real components and real application data.
- Names, counts, alerts and timestamps visible in the reference are design examples, not production data.
